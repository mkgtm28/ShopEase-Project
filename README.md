# 🛒 E-Commerce Website

A modern full-stack e-commerce web application built with **React.js, Django REST Framework, and MySQL**.

The project provides a complete shopping experience with a responsive interface, user authentication, product browsing, cart management, wishlist, checkout, and order tracking.

---

## ✨ Features

* 🔐 User Authentication
* 🛍️ Product Browsing
* 🔎 Product Search & Filtering
* ↕️ Sorting & Pagination
* ❤️ Wishlist
* 🛒 Shopping Cart
* 📦 Order Management
* 👤 User Profile
* 📱 Responsive Design
* 🔄 JWT Authentication

---

## 🛠️ Built With

**Frontend**

* React.js
* React Router
* Axios
* Vite
* CSS

**Backend**

* Django
* Django REST Framework

**Database**

* MySQL
